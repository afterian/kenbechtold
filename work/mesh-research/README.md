# Advanced Mesh Reconstruction from Photos

*Moving beyond photogrammetry: using Gaussians and photometric stereo to reproduce meshes with smooth, featureless surfaces.*

An interactive research report (static site). Open `index.html` via any web server, or see the published GitHub Pages site.
Press `?` in the report for the interaction guide.

Public benchmarks: DiLiGenT-MV, NeRF synthetic, Skoltech3D. Three.js r180 is vendored under `vendor/three` (MIT licence included).
